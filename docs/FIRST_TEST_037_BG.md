# Първа проверка на 0.3.7

1. Инсталирай INSTALL ZIP през Decky и презареди плъгина. Не изтривай settings
   папката или съществуващия Original. Името остава Trigger Calibration.
2. Преди Read очаквай кратък начален екран. При съществуващ архив има авариен
   Restore Original. Натисни Read Calibration за настройките.
3. Виж 🔒 Original Calibration и липсата на Save. При първа настройка без архив
   първо направи пълно Shutdown и включи Deck, после Read → Save Original и
   потвърди предупреждението. Това не доказва фабричен произход на стойностите.
4. Използвай Export Original Backup и копирай получения JSON от
   Downloads/TriggerCalibrationBackups на друг компютър/носител.
5. Промени Selected, Apply и провери Trigger Test. Read не трябва да променя
   Selected или Original. Close Trigger Test спира следенето.
6. След студено стартиране Read трябва да покаже реалните Current стойности,
   а Selected да запази последния избор. Ръчно Apply е необходимо при желание.
7. Restore Original възстановява архивираните четири стойности; Selected остава
   избраният preset. Не повреждай умишлено истинските си backup файлове за тест.

При грешка запази точния текст, експортите и цялата settings папка. Ако един
архив е повреден, другият се използва без изтриване на историята. При два невалидни
или несъгласни архива възстанови достоверен външен експорт; не запазвай Current
като предполагаем оригинал.
